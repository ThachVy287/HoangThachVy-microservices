# Lab 02 - Room Rental Management Microservices

## Thong tin
- De tai: Quan ly phong tro
- Mon hoc: Lap trinh Web 3
- Cong nghe: Spring Boot, Java, Maven
- Database: MySQL, SQL Server

## Microservices
1. Room Service - MySQL - Port 8081
2. Tenant Service - SQL Server - Port 8082
3. Contract Service - Port 8083
4. Billing Service - Port 8084
5. Employee Service - Port 8085

## Cau truc
- backend: Cac Spring Boot Microservices
- frontend/admin: Giao dien quan tri
- frontend/client: Giao dien nguoi thue
